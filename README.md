# Financial Data Analytics Internship — Yuva

## 📊 Project Overview

This repository contains my six-week financial data analytics project completed as part of the Yuva internship program.

The project follows a progressive financial analytics workflow using publicly available financial data from the **World Bank World Development Indicators (WDI)**.

Across six weeks, the project covers:

- Financial data acquisition and preparation
- Exploratory Data Analysis (EDA)
- Financial forecasting
- Financial risk analysis
- Statistical hypothesis testing
- Data visualization
- Final reporting and recommendations

The objective was to develop a practical understanding of how financial data can be collected, analyzed, interpreted, visualized, and communicated.

The project was designed to develop practical skills in:

## 🔍 Key Financial Indicators

The project primarily examines three banking-system indicators from the World Bank:

### Bank Capital to Assets

Measures bank capital and reserves relative to total assets.

**World Bank Code:** `FB.BNK.CAPA.ZS`

### Non-Performing Loans

Measures non-performing loans relative to total gross loans.

**World Bank Code:** `FB.AST.NPER.ZS`

### Private-Sector Credit

Measures domestic credit to the private sector provided by banks as a percentage of GDP.

**World Bank Code:** `FD.AST.PRVT.GD.ZS`
